# Injected IRC — downloads

Injected is a modern IRC client with a 24/7 cloud bouncer. Sign in with your Injected account to get stored history, highlights, image uploads and typing indicators on every device.

**Get the latest version from [Releases](https://github.com/s4turns/Injected-releases/releases/latest).**

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `Injected-Setup-<version>.exe` |
| Fedora / RHEL (x86_64) | `injected-<version>.x86_64.rpm` |
| Ubuntu / Debian (amd64) | `injected_<version>_amd64.deb` |
| Android | [Google Play (early access)](https://play.google.com/store/apps/details?id=injected.myapp) |
| Web | [injected-irc.com](https://injected-irc.com) |

## Install

**Windows:** run the installer. It isn't code-signed yet, so if SmartScreen says "Windows protected your PC", click **More info → Run anyway**.

**Fedora:**
```
sudo dnf install ./injected-<version>.x86_64.rpm
```

**Ubuntu / Debian:**
```
sudo apt install ./injected_<version>_amd64.deb
```

Each release lists SHA-256 checksums for its files.

This repository only hosts the installers. Injected's source code is not published.
